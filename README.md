# Quiz Master Pro 🎯

A modern and interactive quiz application designed to test and improve your knowledge through engaging quizzes.

## 🚀 Features

- 🧠 Interactive quiz experience
- 📊 Score tracking
- ⏱️ Timed questions
- 🎯 Multiple-choice questions
- 📱 Responsive design
- 🎨 Clean and user-friendly interface

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
